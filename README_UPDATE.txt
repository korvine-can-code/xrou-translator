DVANDVA XROU-HAXA TRANSLATOR — VERSION 4 VOCABULARY UPDATE

CHANGES
- Expanded dictionary: 1,821 entries (346 new; previous 1,475).
- Expanded phrasebook: 405 entries (previous 405).
- Expanded sentence patterns: 47 entries (previous 47).

- Added 70 Xrou words beginning vai- for lexicalized negatives: blind = vai-drishti (no-sight), deaf = vai-shruti (no-hearing), hopeless = vai-asha (no-hope), and more.
- Distinction: vai-shakta = unable (adjective); vai shakta = cannot (verbal construction).

INSTALLATION
1. Extract the ZIP.
2. In your existing GitHub repository, upload all files, including assets, replacing same-named files.
3. Commit to main. GitHub Pages republishes the site.
4. If an old version remains, hard-refresh or clear cached site data.

GRAMMAR NOTE
These are creative, provisional Xrou additions. vai- is the lexical prefix for "without/no [quality]" and unprefixed vai remains an independent negative particle. No automatic negation rule can safely replace every English un-/in-/less adjective.
