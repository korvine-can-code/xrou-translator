Dvandva Xrou-Haxa Translator — Version 23

Canonical vocabulary changes:
- yhadhatu = silver (literally sacred metal)
- yhadhatu-haxa = Faesong (literally silver-speech)
- yha- is the productive sacred/holy prefix (yha + noun, no hyphen).
- yhadhatu-agni = lightning (silver-flame), updated for consistency.
- pavitra remains as a standalone older adjective for holy/sacred, but yha- is the productive compound prefix.
- Yhamakari = sacred spider (illustrative compound).

The engine and word definition popup now recognize sacred compounds, e.g.
"holy wolf" -> yhabhediya and "yhabhediya" -> "holy wolf".
Existing casual/formal registers, favorites, history, synonyms, phrasebook, visuals and request form are preserved.
